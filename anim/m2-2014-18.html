本题讲解：调和变量让 $f'$ 项成对消去——偏微分方程化归为常微分方程

答案：$f(u)=\dfrac{1}{16}\left(e^{2u}-e^{-2u}\right)-\dfrac{u}{4}$。

第 0 步：先立机制——"奇迹消项"不是奇迹

一切"复合函数的偏微分方程反推 $f$"的题，流程固定三段：①设中间变量，算出 $z_{xx}+z_{yy}$；②代入方程，化成 $f(u)$ 的常微分方程；③用初值定常数。本题真正的机关在：$u=e^x\cos y$ 是调和函数——它自己就满足

$$\frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}=e^x\cos y-e^x\cos y=0.$$

链式法则对复合函数二阶求导时，除了 $f''(u)$ 项必然还会拖出一串 $f'(u)$ 项，其系数恰是 $\dfrac{\partial^2u}{\partial x^2}+\dfrac{\partial^2u}{\partial y^2}$——调和性让这一串 $f'$ 项整体归零。所以"两相抵消"是结构性必然，出题人选 $e^x\cos y$ 就是为了这个。

第一步：链式法则求一阶偏导

$z=f(u)$，$u=e^x\cos y$：

$$z_x=f'(u)\,e^x\cos y,\qquad z_y=-f'(u)\,e^x\sin y.$$

第二步：再求一次——为什么会出现 $f'$ 项

对 $z_x=f'(u)\,e^x\cos y$ 再求 $x$ 导时，$u_x=e^x\cos y$ 也要跟着求导（"先乘后导"），于是劈成两项：

$$z_{xx}=f''(u)\,e^{2x}\cos^2y+f'(u)\,e^x\cos y,$$

$$z_{yy}=f''(u)\,e^{2x}\sin^2y-f'(u)\,e^x\cos y.$$

看第二式的结构：$f''$ 项的系数是 $u_y^2$，$f'$ 项的系数是 $u_{yy}=-e^x\cos y$。这就是第 0 步说的机制：$f'$ 项的系数最终全靠 $u_{xx}$ 与 $u_{yy}$ 对账，而 $u_{xx}+u_{yy}=0$，注定相消。$z_{yy}$ 最易漏项：对 $-f'(u)e^x\sin y$ 求 $y$ 导，$-f''(u)e^x\sin y$ 与 $-f'(u)e^x\cos y$ 都要写，漏掉后者，抵消就不成立。

第三步：相加——调和性兑现

$$z_{xx}+z_{yy}=f''(u)\,e^{2x}\left(\cos^2y+\sin^2y\right)+f'(u)\left(e^x\cos y-e^x\cos y\right)=f''(u)\,e^{2x}.$$

两处化简各司其职：$f'$ 项因 $\Delta u=0$ 成对消去；$f''$ 项因 $\cos^2y+\sin^2y=1$ 收拢成一个系数。偏微分方程被压成一条只含 $f$ 的等式。

第四步：代入并约去 $e^{2x}$——为什么可以约

题设右边 $=\left(4z+e^x\cos y\right)e^{2x}$，其中 $z=f(u)$、$e^x\cos y=u$，故右边 $=\left(4f(u)+u\right)e^{2x}$。于是

$$f''(u)\,e^{2x}=\left(4f(u)+u\right)e^{2x}.$$

$e^{2x}>0$ 恒成立，两边同除不改变方程——这一约，把 $x,y$ 彻底送走，剩下纯 $u$ 的常微分方程：

$$f''(u)-4f(u)=u.$$

第五步：解常微分方程——为什么特解设 $au+b$

特征方程 $r^2-4=0$，$r=\pm2$，齐次解 $C_1e^{2u}+C_2e^{-2u}$。右端 $u$ 是一次多项式，按"同次多项式试探"设特解 $au+b$：代入得 $-4(au+b)=u$，比较系数 $a=-\dfrac14,\ b=0$。为什么敢设一次式：$4\neq0$ 不是特征根，多项式空间被 $-4$ 倍地映回自身，一次试探必成功；若右端次数对应的 $\lambda=0$ 恰是特征根，才需要升次重设。

第六步：两个初值定两个常数

$f(0)=0$：$C_1+C_2=0$。$f'(u)=2C_1e^{2u}-2C_2e^{-2u}-\dfrac14$，$f'(0)=0$：$2C_1-2C_2=\dfrac14$，即 $C_1-C_2=\dfrac18$。为什么两个条件刚好够：二阶方程通解含两个自由常数，一个初值定一个。解得 $C_1=\dfrac1{16},\ C_2=-\dfrac1{16}$：

$$f(u)=\frac{1}{16}\left(e^{2u}-e^{-2u}\right)-\frac u4.$$

验算：$f''=\dfrac14(e^{2u}-e^{-2u})$，$4f=\dfrac14(e^{2u}-e^{-2u})-u$，相减得 $u$ ✓；$f(0)=0$、$f'(0)=\dfrac{2}{16}+\dfrac{2}{16}-\dfrac14=0$ ✓。

易错点

  • $z_{yy}$ 漏一阶项：$-f'(u)e^x\cos y$ 不写，$f'$ 项不抵消，整题崩盘——它的存在正是"调和消项"机制的另一半。
  • 忘约 $e^{2x}$：不约就看不出 $f''-4f=u$，方程永远带着 $x,y$ 解不动。
  • 初值方程算错：$f'(0)=0$ 给出 $2C_1-2C_2=\dfrac14$，除以 2 才是 $\dfrac18$，直接令 $C_1-C_2=\dfrac14$ 会差一半。
  • 特解形式乱设：右端是一次多项式，设 $au+b$ 即可；设 $au$ 也可，设指数式反而解不出。
结论：$u=e^x\cos y$ 调和（$\Delta u=0$）⇒ $z_{xx}+z_{yy}=f''(u)e^{2x}$ ⇒ $f''-4f=u$ 配初值 ⇒ $f(u)=\dfrac1{16}(e^{2u}-e^{-2u})-\dfrac u4$。

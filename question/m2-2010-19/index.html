m2-2010-19

微分方程
11 分
设函数 $u=f(x, y)$ 具有二阶连续偏导数, 且满足等式 $\displaystyle 4 \frac{\partial^2 u}{\partial x^2}+12 \frac{\partial^2 u}{\partial x \partial y}+5 \frac{\partial^2 u}{\partial y^2}=0$, 确定 $a, b$ 的值, 使等式在变换 $\xi=x+a y, \eta=x+b y$ 下简化为 $\displaystyle \frac{\partial^2 u}{\partial \xi \partial \eta}=0$
答案

答案：$\left\{\begin{array} { l } { a = - 2 , } \\ { b = - \dfrac { 2 } { 5 } } \end{array}\right.$ 或 $\left\{\begin{array}{l} a=-\dfrac{2}{5}, \\ b=-2 \end{array}\right.$

自评得分：
19

本题讲解：线性变换把二阶 PDE 化成 $u_{\xi\eta}=0$

答案：$\begin{cases}a=-2,\\ b=-\dfrac25\end{cases}$ 或 $\begin{cases}a=-\dfrac25,\\ b=-2\end{cases}$。

第零步：目标形式决定了"要杀谁"

$u_{\xi\eta}=0$ 里只有混合偏导一项，所以变换后 $u_{\xi\xi}$ 与 $u_{\eta\eta}$ 的系数必须同时为零，而 $u_{\xi\eta}$ 的系数只要不为零（可两边同除）即可。自由参数只有 $a,b$ 两个，恰好对应"杀两个纯二阶系数"的两条约束——这决定了路线：链式法则展开、按三项归类、令两个纯二阶系数为零解 $a,b$。

第一步：一阶链式法则

$\xi=x+ay,\ \eta=x+by$ 给出 $\xi_x=\eta_x=1,\ \xi_y=a,\ \eta_y=b$，故

$$u_x=u_\xi+u_\eta,\qquad u_y=a\,u_\xi+b\,u_\eta.$$

第二步：二阶链式法则（三个全要）

对 $x$、$y$ 再各求一次导，每个复合项都走两条链。以 $u_{xx}$ 为例：$u_x=u_\xi+u_\eta$ 再对 $x$ 求导得 $u_{\xi\xi}+u_{\xi\eta}+u_{\eta\xi}+u_{\eta\eta}$，由二阶偏导连续、混合偏导相等，合并成 $u_{\xi\xi}+2u_{\xi\eta}+u_{\eta\eta}$——那个系数 $2$ 就是这么来的。同理

$$u_{xy}=a\,u_{\xi\xi}+(a+b)u_{\xi\eta}+b\,u_{\eta\eta},\qquad u_{yy}=a^2u_{\xi\xi}+2ab\,u_{\xi\eta}+b^2u_{\eta\eta}.$$

第三步：代入原方程并归类系数

$4u_{xx}+12u_{xy}+5u_{yy}=0$ 中三项系数汇总（供第四步对号入座）：

二阶项系数
$u_{\xi\xi}$$4+12a+5a^2$
$u_{\xi\eta}$$8+12(a+b)+10ab$
$u_{\eta\eta}$$4+12b+5b^2$

第四步：为什么 $a,b$ 是同一个二次方程的两根

要只剩混合项，需 $5a^2+12a+4=0$ 且 $5b^2+12b+4=0$——两个系数对 $a$、$b$ 是同一个二次式。这不是巧合：把 $\xi$ 与 $\eta$（即 $a$ 与 $b$）对调，$u_{\xi\xi}$ 与 $u_{\eta\eta}$ 互换而方程形式不变，所以两个系数必是同一函数分别在 $a,b$ 处的取值。更深层看，$5a^2+12a+4=0$ 正是这个 PDE 特征方程的变形：直线 $x+ay=\text{const}$ 的斜率是 $-\dfrac1a$，把它记作 $m=\dfrac{\mathrm dy}{\mathrm dx}$ 代入特征方程 $4m^2-12m+5=0$（由 $4(\mathrm dy)^2-12\,\mathrm dx\,\mathrm dy+5(\mathrm dx)^2=0$ 同除 $(\mathrm dx)^2$），恰好化成 $5a^2+12a+4=0$——选 $a,b$ 本质上是给 $\xi,\eta$ 各选一族特征线方向，双曲型（$12^2-4\cdot4\cdot5=64>0$）保证有两支相异实方向可配。

解根：

$$5r^2+12r+4=0\ \Longrightarrow\ r=\frac{-12\pm8}{10}\in\Big\{-2,\ -\frac25\Big\}.$$

变换必须可逆，故 $a\ne b$（否则 $\xi=\eta$，两个新变量退化成一个），两个根分别配给 $a,b$（可对调）。此时混合项系数 $=8+12\big(-\tfrac{12}5\big)+10\cdot\tfrac45=-\dfrac{64}5\ne0$，两边同除即得 $u_{\xi\eta}=0$。

易错点

  • 只要求一个系数为零：$u_{\xi\xi}$ 与 $u_{\eta\eta}$ 的系数必须同时为零，而它们对 $a$、$b$ 是同一个二次式，所以 $a,b$ 恰是该方程两根。
  • $u_{xy}$ 展开漏项：$u_x=u_\xi+u_\eta$ 对 $y$ 求导产生四条链，合并后是 $a\,u_{\xi\xi}+(a+b)u_{\xi\eta}+b\,u_{\eta\eta}$，中间项系数是 $a+b$ 不是 $2a$。
  • 取 $a=b$：两根相同则 $\xi,\eta$ 线性相关，变换不可逆，"新坐标系"根本立不起来。
一句话：目标 $u_{\xi\eta}=0$ 逼你杀掉两个纯二阶系数；$a,b$ 是同一二次式 $5r^2+12r+4=0$（特征线方向）的两根，取两不同根各配 $\xi,\eta$，中间项系数自动非零。

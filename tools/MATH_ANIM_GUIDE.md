你的任务：为一批题目各写一份**文字讲解**（md）和一个**HTML 交互动画**。

## 文件输出契约（严格遵守）

- 讲解 → `/Users/a24/jiaoben/math302/data/explain/{题号}.md`，如 `data/explain/m2-2019-05.md`

## 题目数据在哪

`/Users/a24/jiaoben/math302/data/questions/{年份}.json` —— 每年一个对象
`{"year", "count", "questions":[...]}`，每题字段：

- `id` 题号（m2-2019-05）、`year`、`number` 卷面题号、`type`（选择题 / 填空题 / 解答题）、`points` 分值

- `answer` 选择题为答案字母；填空题为文本答案；解答题可能为空（结论见 `refAnalysis`）
- `refAnalysis` 原库解析 —— **只作对答案权威依据，禁止整段照抄**（见下）
- `wrongOptions` 干扰项、`tags` 知识点标签

## 原创性约束（本站新增，硬性）

2. 讲解与动画必须由你自己组织推导框架：自己定步骤、自己挑例子、自己写易错点。
3. 若原库解析与官方答案有出入，以 `answer` / 客观题答案字母为准，并在讲解里注明。

## 文字讲解 data/explain/{id}.md

结构（选择题材，大题同理按问展开）：

```
## 本题讲解：{一句话考点}

### 第一步：{标题}
{分析……}

### 第二步：{标题}
{分析……}

### 易错点
- **{错误做法}**：{为什么错}

> 一句话结论（可选）
```

要求：

1. **第一段给答案**：选择题开头写「答案：X」；填空题写「答案：{文本答案}」；
   解答题按问给最终结果。
2. 语言为中文、面向考研复习者，**教思路而非抄答案**：为什么选它、其他项错在哪。
3. 计算类给出**可复现的逐步推导**（表格、状态序列、关键等式）。
4. 大题（解答题）按问逐问讲解，先给答题框架再填细节，与参考答案口径一致。
5. **md 语法限制**（站点渲染器只支持这些）：`##`/`###`/`####` 标题、段落、`**粗体**`、
   `` `行内码` ``、无序列表 `- `、有序列表 `1. `、表格 `| a | b |`、引用 `> `、`[链接](url)`。
   **允许**：数学式 `$..$`（行内）与 `$$..$$`（独立公式），KaTeX 语法，
   如 `$\lim_{x\to 0}\frac{\sin x}{x}$`。
   **禁止**：图片、嵌套列表、任务列表、脚注、html 标签。
6. **数学式书写注意**（渲染器按这些规则透传）：
   - `$..$` 不跨行；`$$..$$` **支持跨行**（换行书写的展示公式也能正常渲染），
     但不要在公式对内部混入空行或其他 Markdown 结构。
   - 表格单元格里的公式**不要用裸 `|`**（会破坏表格分列）：绝对值写 `\lvert x\rvert`
     或 `\mid`，行列式用 `\begin{vmatrix}`。
   - 行内码 `` ` `` 里的内容是字面量，其中的 `$` 不会被渲染成公式。
7. 长度 200–600 字为宜，表格式推导不限。

## HTML 动画 anim/{id}.html

### 模板选择

- **算法/过程类**（求极限逐步变形、积分计算、泰勒展开逐项、微分方程求解流程、
  矩阵消元/对角化、递推数列、二重积分化累次、旋转体切片……）
  → 复制 `tools/anim_math_algo_template.html`
- **概念/记忆/推理链类**（概念辨析、可导/连续/可微关系、极值拐点判定、
  敛散性判别、特征值性质、二次型正定、选项逐项推演……）
  → 复制 `tools/anim_math_concept_template.html`

复制模板到 `anim/{id}.html` 后**只修改 `AW.init({...})` 区域**（模板里有标注）。
模板已引用 `../assets/anim.css`、`../assets/anim-engine.js` 与本地 KaTeX
（`../assets/katex/katex.min.css`、`katex.min.js`、`contrib/auto-render.min.js`），
**引用路径写 `../assets/…`**：anim/ 与 tools/ 同为站点一级目录，两处都成立；
勿写 `../../assets/…`（会逃出站点根导致 404）。

### KaTeX 在动画中的用法（本站新增，硬性）

1. **每个 snap 渲染后对 stage 调用 `renderMathInElement`**（delimiters 含 `$` 与 `$$`，
   `throwOnError:false`）——两个模板都提供了 `renderMathAfterSnap(stage)` 帮助函数
   （stage 同步渲染；结论卡与标题/副标题由引擎在 render 返回后才写入或只写一次，
   用 `setTimeout(0)` 兜底渲染；刻意不用 `requestAnimationFrame`——后台/隐藏标签页
   rAF 可能永不触发，公式会静默不渲染）：
   - 概念模板：已注入统一 `render`（写入 `sn.html` 后调用 `renderMathAfterSnap`），
     你只需在 `STEPS` 的 `body` 与 `result.html` 里写公式，无需再改；
   - 算法模板：你自写的 `render(stage, sn, i)` **末尾必须调用** `renderMathAfterSnap(stage)`。
2. 公式可写在：`build` 建立的持久 DOM、`sn.html`、`result.html`、`title/subtitle` 里
   （helper 会渲染 stage、结论卡与标题/副标题）。
   **status 栏 / 过程日志 / 序号带是引擎直接注入的纯文本区域，公式写在那里不会被渲染**
   ——日志请用大白话（如「分子分母同时除以 x」），需要公式的内容放进 stage 或结论卡。
3. JS 字符串里的 TeX 命令**反斜杠必须双写**：写 `'\\frac{a}{b}'` 而不是
   `'\frac{a}{b}'`（后者中 `\f` 是换页转义、`\t` 是制表符，公式会被静默破坏）。
4. 禁止运行时外部 CDN：KaTeX 已 vendor 在 `assets/katex/`，不要引入任何网络资源。

### 硬性要求

1. 全中文、自包含逻辑、禁止任何外部 CDN/网络请求。
2. 每步一个 snap：`cls`（ok/miss/shift/step/done）、`tag`、`log`（一句大白话）、
   `count`（累计计数）、需要点亮序号带的给 `ribbon:{k, ok}`。
3. **步数 5–18 步**；**最后一步必须 `done:true`**，并配 `result:{big, html}` 结论卡
   （含正确答案与记忆点）。
4. 涉及数列/格子/表格的演示，用引擎小工具：`AW.cellRow(chars, classes, ptrMap)`、
   `AW.shiftTo(el, idx, pitch)`、`AW.el(tag, cls, html)`；CSS 类
   `aw-box ok|hit|miss|dim`、`aw-stepcard good|bad|key` 可直接用。
5. 颜色语义与引擎一致：绿=正确/命中、红=错误、琥珀=关键/变形、蓝=普通信息。
6. 动画必须**只依据本题数据**（题干、选项、`answer`/`refAnalysis`），不得引入题目外
   的假设；若一道题有多种解法，演示最标准的一种，其余在讲解里说。

### 题型注意事项（本站新增）

- **选择题**：推理链逐项推演 A–D（对应 `options` 与 `wrongOptions`），结论卡给出
  答案字母 + 一句话记忆锚点；答案必须与 `answer` 字母一致。
- **填空题**：`answer` 是文本答案，注意**等价形式核对**——结论卡给出的答案必须在
  数学上与 `answer` 等价（如 `2x+1` 与 `1+2x`、`\frac{\sqrt2}{2}` 与 `\frac1{\sqrt2}`、
  区间开闭写法），不得只抄字面也不得改成一个不等价的“化简”结果；
  讲解里注明等价写法。
- **解答题**：**按问逐步**——(1)(2)(3) 每问至少一段独立步骤，关键推导（换元、
  分部积分、构造辅助函数、判别式计算）各占一步；结论卡按问列出最终结果，
  与 `answer`/`refAnalysis` 的结论一致。
- **含图题**（几何应用、积分区域、旋转体等）：题库数据没有图，动画与讲解里
  **用文字/表格描述几何结构**：区域边界曲线方程、交点坐标、积分区域的不等式表示、
  截面形状等，一律不得引入图片或外部链接。
